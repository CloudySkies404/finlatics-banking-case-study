# Finlatics Banking Case Study

A data analysis project completed as part of the Finlatics Data Science program. The project explores banking marketing data to understand customer characteristics and factors related to term deposit subscriptions.

## Project Overview

The aim of this case study is to explore the dataset, identify patterns in customer information and marketing campaigns, and answer the questions provided in the assignment.

## Work Included

- Data inspection and understanding
- Exploratory data analysis
- Summary statistics and visualizations
- Analysis of customer and marketing campaign information
- Findings related to term deposit subscriptions

## Dataset

The project uses banking marketing data containing customer details, campaign information, and a term deposit subscription outcome.

## Technologies Used

- Python
- Pandas
- Data visualization
- Google Colab

## Project Files

- `Finlatics_Banking_Case_Study_Clean.ipynb` — notebook/report file uploaded for the case study
- `Finlatics_Banking_Case_Study_Presentation.pptx` — project presentation
